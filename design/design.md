### 警告(稀にしか使わない — プリンシプル「赤の警告色を多用しない」)

| トークン | 値 |
|---|---|
| `warn` | `#D8654E` |

⚠️ **`warn` は「録画中」の点滅ドット等、ごく限定的な用途のみ。失敗や赤警告としては使わない。**

### なぜこの配色か

- **冷→暖が色相そのもので反転する唯一の案。** 比較したA(緑一色)は「暖かさ」を表現できず、B(紙+テラコッタ)はセッション中に「冷たさ」を作れず、C(紫+ライム+ピンク)はチープさの禁止事項に抵触した。
- **琥珀(`#FFB02E`)は studytok フィードで相対的に空いている色域。** 既存の集中/学習アプリは緑・紫・ピンクに集中しており、識別性(UX①の配布インフラ要求)に直接効く。
- 暗い `base` は、出力動画の背景(実際のカメラ映像=暗い部屋)の上にUIが自然に乗る。

## 2. タイポグラフィ

| 用途 | フォント | ウェイト | 備考 |
|---|---|---|---|
| スコア数字・大見出し | **Inter Tight** | 900(大きい数字) / 800(見出し) | `tabular-nums`、`letter-spacing: -0.03em` |
| UI本文・ラベル | **Inter** | 400 / 500 / 600 / 700 | |
| 日本語 | **Noto Sans JP** | 400 / 500 / 700 / 900 | Inter と併用(英数字はInter優先) |

- 入手経路: `expo-google-fonts`(Inter Tight・Inter・Noto Sans JP すべて提供あり)。実装コストほぼゼロ。
- スコアの `/100` のような補助数字は本体の `0.32em` 前後・`opacity .55〜.6` で親数字にぶら下げる(`<sup>` 相当)。

## 6. マスコット(ミーアキャット)確定仕様

### 絵柄タッチ: **立体(ソフトな3D的陰影)を主役 + 極小サイズ用にフラットのシルエット版を別途持つ**

- 通常表示(アプリ内・アプリアイコン・オンボーディング・動画の200px級プレビュー)は立体版
- 動画の隅に常駐する極小マーク(サムネイルで約18px相当)だけフラットのシルエット版に差し替える
- Duolingo・Slack・Airbnb 等と同じ構造。実装コストは SVG を2種持つだけで軽微
- **必須条件:** フラット版のシルエットは立体版と一致させること(輪郭が変わると「別のキャラ」に見えて識別性が壊れる)

### 毛色: **固定(リアル準拠・サンディタン)。冷/暖で変わるのは目の光と輪郭のリムライトのみ**

- 2026-07-31、実際に生成したキャラクター参考画像(チビキャラ・3Dレンダー調、白背景、6ポーズのキャラクターシート)をもとに確定。**スモーク案は撤回。**

| 部位 | 値(参考画像から抽出) | 可変/固定 |
|---|---|---|
| 体毛(メイン) | `#C9A574` サンディタン | 固定 |
| お腹・あご | `#EDE0C8` クリーム | 固定 |
| アイパッチ(目の周り) | `#3D2C22` ダークブラウン(純黒でなく茶寄り) | 固定 |
| 鼻 | `#1A1512` | 固定 |
| 手足・尻尾の先 | `#4A3527` ダークブラウン | 固定 |
| 耳の内側 | `#4A3527` | 固定 |
| 瞳・光彩 | `#7C93A8`(冷) → `#FFB02E`(暖、`#FF7A45`寄りも可) | **可変** |
| 輪郭のリムライト | 瞳と同じ値に同期 | **可変** |

**判断理由:**
- 実物準拠(サンディタン)は「かわいい動物マスコット」カテゴリ全体がこの色域に集中しており、毛色そのものでの識別性は弱いという懸念を出したが、**実際の生成結果のクオリティ・愛着の強さがそれを上回ると判断し、こちらを採用。**
- **識別性の担保は毛色でなく「瞳とリムライトの色」に一本化する。** セッション中=青灰・終了後=琥珀に瞳と輪郭が光る演出は毛色に関係なく機能するので、この判断で識別性(UX①)を犠牲にしていない。毛色は普通のミーアキャットのまま、差別化は瞳が担当という役割分担。

### 確定した絵柄の方向性

参考画像のテイスト(丸みのある3Dレンダー調・大きな瞳・チビキャラプロポーション、白背景の複数ポーズシート形式)を**本番イラストの基準にする**。当初の design.md 案「dimensional soft-3D、not overly cute」からはやや"cute"寄りに振れているが、04_マスコット.md の「終わったら全力で讃える」「見下さない厳しさ」とは矛盾しない(可愛さと厳しさは両立可能。セッション中の無表情・不動のポーズで温度差を作る)。

### 二態(仕様は元の `04_マスコット.md` から変更なし)

| | セッション中(見張り) | セッション終了後(讃える) |
|---|---|---|
| 姿勢 | 直立・微動だにしない | 崩れる・全身で喜ぶ |
| 目 | 瞬きしない | 細まる・笑う |
| 発話 | 最小限 | よく喋る |

### 画像生成プロンプト(参考・`design/mock/index.html` §04の検証を経て確定)

冷/暖それぞれの完成プロンプトは作業ログ側に記録済み。再生成する場合は上記の固定色/可変色の表を正とする。

┌─────────────────────┐
