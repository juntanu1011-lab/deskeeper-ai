## 影について

**どのファイルにも影は入っていない。** LP では `Wordmark.tsx` が
`filter: drop-shadow(...)` をマスコットに当てて、キャラを紙の上に座らせている。
これは LP の地の上で効く演出であって、PNG に焼き込むと**置いた先の明るい面すべてに
灰色のにじみが出る**。影が要る用途では、置く側で付けること。

## 作り方（再現用）

単一の画像ファイルとしての「LPロゴ」は存在しない。ロックアップは
`web/components/brand/Wordmark.tsx` の `variant="peek"` が
**マスコット PNG + Bricolage Grotesque 800 の "Kept"** をその場で組んでいるだけ。
なので書き出しは「本物のコンポーネントをブラウザで大きく描かせて撮る」方式を取っている
（実装と配布物が食い違わないため）。

1. `web/app/logo-export/page.tsx`（**書き出し後に削除済み**）を一時的に置き、
   `<Wordmark size="l" variant="peek" assetBase="/logo-export/">` を `zoom: 20` で単独描画。
   マスコットは LP の `mascot-peek.png`（286×480）ではなく同一原画の
   `peek-master.png`（549×920）を `web/public/logo-export/mascot-peek.png` に置いて使用
   — Wordmark の `PEEK_AR = 549/920` はこの原寸のこと。
   - ページは `width: max-content` + **余白 400px**。マスコットは 1em の箱に対して 1.3em あり
     わざと箱からはみ出すので、余白が足りないとドキュメント端で切れる（1度切った）。
   - `img{filter:none}` で影を無効化。
2. dev サーバ上で **純黒の地** と **純白の地** の2回撮影
   （`cockpit browser screenshot --full-page`、DPR 2）。2枚が同寸で揃うことが前提。
3. `export_lockup.py` で真のアルファを復元する: `a = 1 − (C_white − C_black)/255`、
   色は `C_black / a`。スクリーンショットは不透明なので、これをやらないと透過版が作れない。
   アンチエイリアスの階調まで正確に出る。
4. アルファのバウンディングボックスで自動トリム → 各サイズを書き出し。

⚠️ Next.js の dev インジケータが写り込むので `nextjs-portal{display:none}` を当てている。
座標クロップで消そうとすると**マスコットの左端を切る**（1度やった）。

## 明色版の作り方の注意

文字だけを `#0A0C10` に置換する処理は、**「明るくて無彩色」で判定してはいけない。**
マスコットの白目は純白 `#FFFFFF` で条件を通ってしまい、**両目が黒く潰れる**（1度やった）。
`--ink` = `#EDEFF3` は青寄り（b > r）で純白にはないズレがあるので、
インク色そのものへの厳密一致 + `b >= r` で分離する。

## 既知の見え方

- 目の白と瞳の境界にわずかな粒状感がある。549px の原画をブラウザが約1.5倍に拡大して
  描いたものを撮っているため。実使用サイズでは見えない。
- マスコットの体の右端と K のステムの間にわずかな隙間がある。ブランド地の上では見えないが、
  明るい地に置くと縦の筋として出ることがある。
- ベクター版（SVG）は未整備。`design/logo-trace/README.md` の「清書完了の定義」を参照。
