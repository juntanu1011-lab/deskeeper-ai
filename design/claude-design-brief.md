# Deskeeper — Claude Design 投入用ブリーフ

> **使い方:** このファイルをそのまま Claude Design(claude.ai)の新規デザインシステムに貼り付ける。
> 一緒に `tokens/tokens.json`(数値トークン)と、できあがったミーアキャットの画像(冷/暖2ポーズ)を
> ブランドアセットとして追加する。目的は「オンボーディング→使う→結果→シェア」の全画面を
> **クリックで繋がるインタラクティブなプロトタイプ**として一気に組むこと。まだコードは書かない。

---

## 0. これは何のアプリか(一文)

> 集中できない自分に嫌気がさしている英語圏の学生が、Deskeeperに机へ縛りつけられ、
> その2時間の証拠を自分から投稿して「今日はやれた」と言う。

スマホを机に立てかけて自分に向ける → オンデバイスの視線・姿勢判定で集中率を測る →
終了後にスコアと勉強時間を焼き込んだタイムラプス動画が自動生成され、そのまま TikTok/Instagram に投稿できる。

## 1. 誰のためか / 誰のためではないか

- ターゲット:「やらなきゃいけないのにできない」が慢性化していて、**その苦しさを"見せる"ことで乗り越えようとする**学生(study with me 文化圏)
- 明示的に狙わない: 試験直前の独学者(投稿しない層) / 純粋な生産性オタク・社会人(感情が動かない) / 「勉強する人みんな」(解像度が下がる最悪の答え)

## 2. デザインプリンシプル(優先順位。横槍が入ったら常にここに戻る)

| # | 優先する | 犠牲にする |
|---|---|---|
| 1 | 投稿したくなる動画の質 | 集中スコアの精度 |
| 2 | セッション中の冷たさ | 常時の優しさ |
| 3 | 一人で完結すること(0人問題を踏まない) | 他人とつながる楽しさ |
| 4 | 開いて5秒で始まる | 細かく設定できること |
| 5 | **恥を誇りに変える(絶対に外せない)** | 恥を突きつけること |

⚠️ Claude Design への指示: **失敗の赤を多用しない。連続記録(streak)が「折れた」ことを見せる表現は作らない。** セッション中のコピーは淡々と事実を告げるだけで、評価・皮肉・叱責の言葉を入れない。

## 3. 核となる二態(最重要の設計要求)

|  | セッション中 | セッション終了後 |
|---|---|---|
| 温度 | 冷たい | 暖かい |
| 動き | 静止・緊張 | 解放・弾む |
| 色 | 抑制された青灰 | 鮮やかな琥珀が解放される |
| マスコット | 直立不動・無表情・瞬きしない | 崩れる・全身で喜ぶ・目を細める |

## 4. 全画面フロー(この順に、繋がった形でプロトタイプ化してほしい)

### ステージ① 知る(プロトタイプ対象外・文脈の参考情報)
TikTok/IG の studytok タグ経由で発見される。出力動画そのものが最大の発見装置。

### ステージ② アクセスする

1. **初回起動** — セッション開始を強制しない。「次に勉強するのはいつ?」を1問だけ聞いて通知許可を取る
2. **パーソナライズ質問(3〜5問)** — ドラフト案:
   - Q1「主にどの科目を頑張りたい?」
   - Q2「集中を切らす原因は何?」(スマホ / 眠気 / 周りの音 など)
   - Q3「厳しく言われたい? そっと見守られたい?」← **鬼モード/静音の初期値を決める質問**(前回の検討で、テーマ選択の代わりにここでマイクロコミットメントを作ると決定済み)
   - Q4「1日どれくらい机に向かいたい?」
   - 全問スキップ可・複数選択可にする(離脱防止)
3. **「あなた専用の設定を作っています…」ローディング** + 社会的証明
4. **★サンプル出力動画の再生** — まだ1回も使っていない段階で価値を見せる。Deskeeper 固有の強み(価値が映像なので体験前でも見せられる)
5. **ペイウォール①** — 7日間トライアル、年額 $39.99 を既定選択で提示
6. 断った場合 → 無料層(1日1セッション・透かし大)のホーム画面へ

### ステージ③ 使う

7. **ホーム** — 今週の合計時間、モード(カメラ/シンプル)と厳しさ(鬼/静音)の選択チップ、科目タグ、「机に置く」ボタン。開いて5秒で到達
8. **立てかけガイド** — カメラ映像+輪郭オーバーレイ+距離判定。「置いたら、もう触らない。」の一言で儀式化
9. **セッション中(冷)** — 情報を極限まで削った画面(視界の端でチラ見するためだけの画面)。時刻のみ大きく、マスコットは画面下部に**小さく・薄暗く・完全不動**で常駐(青灰 `#7C93A8` の瞳だけが生きている。アニメーションループなし)。【2026-08-03確定】録画される不気味さを「見張り番がいる」に変換する役割と、終了時の冷→暖反転(ずっと不動だった奴が崩れて喜ぶ)の物語を担うため、非表示案・接触時のみ出現案は見送り
10. **鬼モードの割り込み**(未プロトタイプ・要追加) — スマホに手を伸ばした/よそ見をした瞬間の音・振動・一瞬の画面変化。**叱責語は禁止**、事実だけ告げる(例:「席を外していた。12分」)
11. **セッション終了(冷→暖の反転)** — 640msでゆっくり色温度が反転する演出そのものを1画面として作る
12. **結果画面(暖)** — スコア・時間・マスコットが讃えるポーズ。ここが感情のピーク
13. **出力動画プレビュー + ペイウォール②** — 「透かしなしで書き出す?」を今使った機能に対して提示
14. **シェア導線** — TikTok/IGへの共有。急かさない・摩擦を最小に

### ステージ④ 結果が残る(未プロトタイプ・要追加)

15. **履歴/ライブラリ画面** — 動画が溜まっていく資産としての一覧。**streakが折れる表現は禁止**
16. **通知** — マスコットが送ってくる体で作る通知プレビュー(ロック画面イメージ)

## 6. 出力動画スコアカード(=実質のロゴ。最重要の固定要素)

無料ユーザー全員の動画がこの見た目で拡散される「配布インフラ」。**サムネイルサイズ(58px前後)でも識別できることが必須要件。**

```
[マスコット小] Deskeeper
87/100   ← Inter Tight 900・琥珀色
▬▬▬▬▬▬▬▬░░░  ← 琥珀グラデーションのバー
2h 14m · 科目
```

3形式ある(設定で選択、Pro限定):① 顔あり引き画 ② 顔ボカシ/絵文字追従(カメラモード既定) ③ 集中率グラフのみ(シンプルモード出力)。3形式ともこのスコアカード要素は共通で固定。

## 7. デザイントークン(要約。詳細は同梱の `tokens.json` を参照)

## 8. マスコット(ミーアキャット)確定仕様

- **絵柄**: 立体・ソフトな3Dレンダー調(添付の参考画像と同じテイスト)を主役に、極小サイズ(動画の隅・約18px相当)だけフラットのシルエット版に差し替える。**フラット版の輪郭は立体版と一致させること。**
  - 【2026-08-03 刷新検討中】3Dレンダー調は「AI生成感」が強いため、**2D手描きラフ線タッチ**(ゆらぎのあるペン線・フラット塗り・デフォルト真顔)への刷新を試作中。試作プロンプトと評価基準は `design/mascot-2d-trials/prompts.md`。確定したらこの節を更新する
- **毛色は固定**(サンディタン `#C9A574` ・お腹クリーム `#EDE0C8` ・アイパッチ `#3D2C22` ・鼻 `#1A1512` ・手足 `#4A3527`)。実物のミーアキャットに近い配色。
- **可変なのは瞳と輪郭のリムライトだけ**: セッション中は青灰 `#7C93A8`、終了後は琥珀 `#FFB02E`〜`#FF7A45` に光る。**識別性はここが担う(毛色ではない)。**
- 二態: セッション中=直立不動・瞬きしない・無表情 / 終了後=崩れる・全身で喜ぶ・目を細める。発話はセッション中は最小限、終了後はよく喋る
- 通る場所: オンボーディング(案内役)/ セッション開始(空気が変わる演出)/ セッション中(画面下部に小さく・薄暗く・完全不動で常駐。§4-9参照。発話は声と音で最小限)/ 終了(反転の主役)/ 出力動画の隅(実質のロゴ)/ 通知(送り主)/ アプリアイコン(主役)
  - 【2026-08-03】旧記述「セッション中は画面には出ない」は§4-9と矛盾していたため、「出す(小さく・薄暗く・完全不動)」に統一して解消

## 9. Claude Design への具体的な依頼文(このまま貼ってもよい)

> 上記のブリーフをもとに、Deskeeper という学習集中アプリの全画面をインタラクティブなプロトタイプとして作ってください。
> スタイルは「Keeper」方向 — 暗い下地に、セッション中は青灰、セッション終了後は琥珀色が解放される、色温度そのものが反転する二態のデザインです。
> 添付の tokens.json の値を厳密に使ってください。添付のミーアキャットの画像(見張りポーズ/讃えるポーズ)をマスコットとして全画面に一貫して使ってください。
> 4章の全画面リストの順番でフローを繋げ、特にステージ③(使う)の冷→暖の反転を1つの体験として作り込んでください。
> 出力動画のプレビュー画面では、6章のスコアカードのレイアウトを再現し、58px相当に縮小しても識別できるかを確認できる形にしてください。
